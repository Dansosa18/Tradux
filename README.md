# Tradux 🌐
### Simulador de Compilador Traductor Inglés ↔ Español

**Tradux** es un simulador de compilador capaz de traducir oraciones entre inglés y español, aplicando los principios fundamentales de la construcción de compiladores.

## ¿Qué hace?
- Análisis léxico, sintáctico y semántico
- Generación de tabla de símbolos y tabla de errores
- Traducción Inglés → Español y Español → Inglés
- Carga de archivos .txt
- Árbol de derivación con BNFs

## Tecnologías
- HTML / CSS / JavaScript
- Python
